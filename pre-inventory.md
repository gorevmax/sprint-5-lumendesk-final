# Предварительный реестр исходных файлов LumenDesk

Дата составления: 2026-11-18. Основа: [spec.md](spec.md), [project-task.md](project-task.md).
Охват: все 50 файлов в `documents/`. Исходники не изменялись.

Это предварительный реестр: он фиксирует факты, на основе которых затем будет составлен `inventory.csv`. Окончательные решения `include` / `exclude` в нём не принимаются.

## 1. Как составлен реестр

- Текст извлечён из всех файлов: md/txt/csv — напрямую (UTF-8); docx — из `word/document.xml` и свойств документа; xlsx — со всех листов, включая формулы; pdf — постранично через `pypdf`.
- Сведения о происхождении, дате, назначении и ограничениях взяты **из текста документов**: вводных абзацев, подписей команд, дат, пометок вида «Только руководителям поддержки». Признаки из имени файла и папки («копия», «final», «новый», «Рабочие копии», «Downloads», «Архив») использованы только как дополнительные.
- Полей метаданных из постановки (`id`, `title`, `owner`, `version`, `updated`, `permission`, `sensitivity`, `inclusion_status`) нет ни в одном файле. В свойствах всех 8 docx стоит одна и та же дата создания и изменения `2026-09-15T00:00:00Z` и поле `title`, у PDF заполнено только `/Title`. Дата в свойствах docx одинакова у всех файлов и, по-видимому, означает дату сборки, а не редакции. Поэтому за дату документа принята дата из текста.
- Дубли проверены попарным сравнением нормализованного текста (мера Жаккара по словам и посимвольное сходство). Переводы на другой язык сопоставлены вручную.
- В цитатах сохранён язык оригинала.
